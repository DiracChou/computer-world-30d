# Computer World 30D

这是“计算机世界基础打通训练”的统一学习仓库。

目标不是在 30 天内堆积术语或完成大量代码，而是通过“预测 → 实验 → 观察 → 解释 → 修改 → 再验证”，建立一张能继续扩张的计算机世界地图。

## 三方分工

- 学生：预测结果、亲手实验、用自己的语言解释、做决定。
- ChatGPT 教授：第一性原理解释、知识体系、概念纠错、阶段考试。
- Codex 实验助教：实验脚手架、环境、测试、Debug、仓库维护与工程观察。

## 每日使用方式

1. 开始前阅读 `ROADMAP.md`、`LEARNING_LOG.md`、`QUESTIONS.md` 和 `PROFESSOR_HANDOFF.md`。
2. 当天只确定一个主问题，并写下自己的预测。
3. 在 `experiments/day-XX/` 中运行和修改最小实验。
4. 记录观察结果；先由学生解释，再讨论结论。
5. 用 3～5 个闭卷问题检查理解，根据证据更新日志和概念图。

## 运行原则

程序运行成功不等于学生掌握。只有学生能解释、预测、修改或迁移，才把概念加入 `CONCEPT_MAP.md`。
